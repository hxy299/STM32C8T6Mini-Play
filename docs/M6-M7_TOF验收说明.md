## 1. 拓扑与引脚

```text
                    ┌─────────────────────┐
                    │  桌宠俯视            │
                    │      [TOF3]         │  ← 前脸：测障碍（朝前）
                    │        ↑            │
                    │   [TOF1]   [TOF2]   │  ← 底部左/右：测桌面（朝下）
                    │      \     /        │
                    │      [TOF0]         │  ← 底部前：测桌面（朝下）
                    │        ↓            │
                    └─────────────────────┘
```

| 编号 | 位置 | 角色 | 危险方向 | I²C 地址 | XSHUT |
|---|---|---|---|---|---|
| TOF0 | 底部前 | 桌沿 | 距离**变远** | `0x30` | **PA4** |
| TOF1 | 底部左 | 桌沿 | 距离**变远** | `0x31` | **PA5** |
| TOF2 | 底部右 | 桌沿 | 距离**变远** | `0x32` | **PA8** |
| TOF3 | 前脸 | 障碍 | 距离**变近** | `0x33` | **PB5** |

### I²C1

| 项 | 值 |
|---|---|
| 引脚 | **PB6 = SCL，PB7 = SDA**（默认复用功能，无需重映射） |
| 模式 | 标准模式 **100 kHz** |
| 上拉 | 模块板载；若用裸芯片需外接 4.7 kΩ 到 3.3 V |
| 供电 | 模块 **VIN 接 5 V**（板上有 LDO），逻辑 3.3 V |

> **每个 XSHUT 必须接 10 kΩ 下拉到 GND。**
> 没有下拉时，上电瞬间芯片状态不确定，地址分配会随机失败，
> 表现为横幅里 `en=0xF` 但 `online=0x0`。

## 2. 为什么必须做地址分配

4 颗 VL53L0X **出厂地址全是 `0x29`**。上电后它们同时响应同一地址，
主机无法区分任何一颗。

`Tof_Init()` 的做法：

```text
1. 所有 XSHUT 拉低  -> 全部关断        （等 10 ms）
2. 逐颗：
     a. 拉高 XSHUT[i]，等 3 ms（内部 boot 约 1.2 ms）
     b. 此时总线上只有这一颗醒着，一定在 0x29
     c. 写寄存器 0x8A = 0x30+i   （地址变更）
     d. 在新地址上做完整初始化
     e. 保持 XSHUT 高，进入下一颗
```

> 未启用的传感器**全程保持 XSHUT 低**，不参与地址分配，
> 也不影响已启用传感器的固定地址映射（TOF2 永远是 `0x32`）。

## 3. 初始化序列（不能精简）

按 ST 官方 API 移植，顺序如下：

| 步骤 | 内容 |
|---|---|
| 1 | 型号确认（`0xC0` == `0xEE`） |
| 2 | DataInit：1V8→2V8、标准模式、读 `stop_variable` |
| 3 | 关掉 MSRC / PRE_RANGE 限值检查；信号率限值 0.25 MCPS |
| 4 | StaticInit：读 SPAD 信息 → 写 SPAD 使能表 |
| 5 | **加载官方调参表（80 条寄存器写入）** |
| 6 | GPIO 中断配置（新样本就绪） |
| 7 | 关 MSRC/TCC，按时序预算重算 final range timeout |
| 8 | **VHV 参考校准**（`SYSRANGE_START = 0x41`） |
| 9 | **相位参考校准**（`SYSRANGE_START = 0x01`） |
| 10 | 恢复序列配置 `0xE8` |

> ⚠️ **第 5 步的调参表、第 8/9 步的参考校准缺一不可。**
> 删掉之后读数会严重偏移，或者干脆不出数。
> 单颗初始化约 200 ms，4 颗合计约 1 秒，期间内部反复喂看门狗。

### 测量参数

| 项 | 值 | 说明 |
|---|---|---|
| 时序预算 | **20 ms** | VL53L0X 允许的最小值（默认 33 ms） |
| 测距模式 | **单次（Single）** | 不用连续模式，避免占满总线 |
| 轮询间隔 | **10 ms**（`TOF_CFG` 可调 10..255） | 两颗之间 |
| 单次超时 | 120 ms | 超时按无效读数处理 |
| 完整一轮 | 约 **120 ms**（4 颗） | |

> 说明书里写的是"每 10 ms 测一颗 → 4 颗 / 40 ms"。
> 实际受 20 ms 时序预算限制，一轮约 120 ms。
> 在 300 Hz 标准档（13.9 mm/s）下，一轮只走 **1.7 mm**，
> 桌沿去抖 3 次约 5 mm，配合 200 步自动回退（4.6 mm）足够安全。

## 4. ★ 两种角色的判定语义**相反**

这是整个阶段最容易写错的地方，已单独做成纯函数并在 PC 上单测。

| | 底部三颗（桌沿） | 前脸一颗（障碍） |
|---|---|---|
| 桌面/空旷 | 15~40 mm | >300 mm 或**无回波** |
| 危险 | 距离**变远** 或**无回波** | 距离**变近** |
| **无回波算什么** | **危险**（正下方没桌面了） | **安全**（前方空旷） |
| 触发阈值 | `> 80 mm` | `< 150 mm` |
| 解除阈值 | `<= 60 mm` | `>= 200 mm` |
| 去抖次数 | 3 | 2 |
| 恢复方式 | **必须 `CLEAR_FAULT`** | 障碍消失**自动**恢复 |

### 如果两者写成同一套会怎样

| 错误写法 | 后果 |
|---|---|
| 底部把"无回波"当安全 | **冲到桌沿时读数无效 → 不报警 → 直接掉下去** |
| 前脸把"无回波"当危险 | 前方空旷永远无回波 → **机器人永远动不了** |

这两条都有专门的单元测试守着
（`test_tof_math.c` 的第 [4] 和 [8] 组）。

### 触发行为

**桌沿（最高优先级）**

```text
1. 立即停止所有步进脉冲
2. 反向回退 200 步 @120 Hz
3. 上报 EDGE_DETECTED(sensor, dist_mm)
4. 置 FAULT_EDGE，拒绝前进/转向，只接受后退
5. 需 CLEAR_FAULT(bit0) 才恢复
```

**障碍（更温和，允许自行脱困）**

```text
1. 停止前进（后退与转向仍允许）
2. 上报 OBSTACLE_DETECTED(dist_mm)
3. 置 FAULT_OBSTACLE
4. 障碍消失并回到 200 mm 以上 -> 自动清除，无需 CLEAR_FAULT
```

> 为什么不同：桌沿是"掉下去就摔坏"，必须人工确认；
> 障碍是"撞一下没事"，允许自动脱困，否则会卡在墙边出不来。

## 5. 协议

### TOF_CFG（`0x04`）

| 字段 | 长度 | 说明 |
|---|---|---|
| `poll_ms` | 1 | 两颗之间的间隔，10..255 ms |

响应：`ACK(0x00)`；若被钳位则 `ACK(0x01)`；一颗都不在线则 `NAK(0x06)`。

### 事件

| OP | 名称 | Payload |
|---|---|---|
| `0x91` | `EDGE_DETECTED` | `sensor(1) + dist_mm(2, 大端)` |
| `0x92` | `TOF_DATA` | `mask(1) + d0..d3(各 2 字节大端)` |
| `0x95` | `OBSTACLE_DETECTED` | `dist_mm(2, 大端)` |

- `TOF_DATA` 每 **200 ms** 上报一次（`TOF_DATA_PERIOD_MS`）
- 无效读数用 **`0xFFFF`** 表示
- `mask` 的 bit n = TOF n 在线

### CLEAR_FAULT（`0x05`）

| flag | 含义 |
|---|---|
| bit0 | 清桌沿故障 |
| bit1 | 清障碍故障 |
| 0 | 清全部可清故障（兼容旧上位机） |

## 6. 验收步骤

### 6.1 上电自检

看串口横幅：

```
 tof    : en=0xF online=0xF  poll=10ms  edge>80mm obs<150mm
```

| 现象 | 含义 |
|---|---|
| `en=0xF online=0xF` | ✅ 四颗全部初始化成功 |
| `en=0xF online=0x3` | ⚠️ TOF2/TOF3 没起来，查这两颗的 XSHUT 下拉和接线 |
| `en=0xF online=0x0` + `WARN` | ❌ 一颗都没起来，查 I²C 上拉 / 供电 / 地址分配 |

> `online` 是**实测**位图，比任何推断都可靠。

### 6.2 读距离

```cmd
cmd> tofd 15
```

```
 T0=底部前  T1=底部左  T2=底部右(均测桌沿)  T3=前脸(测障碍)
---- = 无回波/无效
  T0 =   18 mm   T1 =   22 mm   T2 =   21 mm   T3 =  480 mm
  T0 =   18 mm   T1 =   22 mm   T2 =   21 mm   T3 =  480 mm
```

| 判据 | 合格线 |
|---|---|
| 底部三颗在桌面上 | 15~40 mm，且**读数稳定**（波动 < 5 mm） |
| 前脸空旷 | >300 mm 或 `----` |
| 四颗同时有读数 | 说明地址分配正确，没有互相干扰 |

### 6.3 桌沿触发（**核心验收**）

```cmd
cmd> tofd 30
```

把机器人放在桌边，**慢慢往边缘推**：

```
  T0 =  110 mm   T1 =   20 mm   T2 =   20 mm   T3 =  480 mm
  >>> 桌沿触发！ TOF0  dist=110 mm
  [FAULT] 0x02(EDGE)
```

| 判据 | 期望 |
|---|---|
| TOF0 越过 80 mm 后 | **约 3 次轮询内**触发（< 400 ms） |
| 触发瞬间 | 电机**立即停**，随后反向回退 200 步 |
| `sst` 位置 | 回退后位置减少约 200 |
| 之后发 `fwd` | **NAK(0x03)**，拒绝前进 |
| 之后发 `bck` | **ACK(0x00)**，允许后退脱困 |
| `c` 清故障后 | 恢复正常运动 |

### 6.4 障碍触发

```cmd
cmd> tofd 20
```

用手或纸板靠近前脸：

```
  T0 =   18 mm   T1 =   22 mm   T2 =   21 mm   T3 =   95 mm
  >>> 障碍触发！ dist=95 mm
  [FAULT] 0x03(OBSTACLE)
```

| 判据 | 期望 |
|---|---|
| 越过 150 mm 内 | 约 2 次轮询内触发 |
| `fwd` | NAK(0x03) 拒绝 |
| `bck` / `lft` / `rgt` | ACK，允许脱困 |
| **移开障碍到 200 mm 以上** | **自动清除**，无需 `c` |

### 6.5 轮询周期

```cmd
cmd> tof 30        # 改到 30 ms
cmd> tof 5         # 会被钳位到 10，返回 ACK(0x01)
```

## 7. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `en=0xF online=0x0` | 4 颗都没应答 | 量 PB6/PB7 上拉；量 VIN 是否 5 V；确认 XSHUT 下拉 |
| 只有部分 online | 某颗 XSHUT 接线/下拉缺失 | 单独看那颗的 XSHUT 电平（唤醒后应为 3.3 V） |
| 读数一直是 `----` | 时序预算 / 调参表没加载成功 | 确认初始化返回值；检查 I²C 是否有丢字节 |
| 读数固定 8190 | 无回波 | 正常现象：桌沿/空旷都会这样 |
| 四颗读数互相串扰 | 地址没分配成功（还都在 0x29） | 检查 `online` 位图；确认 XSHUT 逐个拉高 |
| 桌沿不触发 | 阈值太高或传感器装得太高 | 量实际离桌高度，按需调 `TOF_EDGE_MM` |
| 一切正常但会掉下桌 | 轮询太慢 / 去抖太多 | 降 `TOF_EDGE_DEBOUNCE` 或调小 `TOF_CFG` |
| I²C 卡死（整机不响应） | SDA 被从机拉低 | 驱动里已有 `I2C1_BusRecover()`，初始化时自动尝试一次 |

### 安全联锁的变化（重要）

原来：只要有故障就 `Stepper_StopAll()`。

现在按方向和来源区分：

| 故障 | 行为 |
|---|---|
| `HEARTBEAT_LOST` / `THERMAL` / `TOF_INIT` / `NO_EDGE_PROTECT` | 无条件停 |
| `EDGE` | 允许**后退**和 TOF 自动回退，其余停 |
| `OBSTACLE` | 只停**前进**，后退与转向允许 |

> 不改这一条的话，桌沿触发后设置故障会让安全联锁立刻把
> **自动回退动作本身**也停掉 —— 回退永远跑不起来。

## 9. 已知限制

| 限制 | 说明 |
|---|---|
| 单轮约 120 ms | 受 20 ms 时序预算限制；4 颗无法做到 40 ms 一轮 |
| 无自动重连 | 掉线的传感器不会自动重新初始化，需复位 |
| 环境光影响 | 强太阳光下量程和精度都会下降 |
| 无温度补偿 | VL53L0X 自带，但极端温度下仍会漂 |
| 遮挡 | 壳体开窗必须对准，否则读数一直 8192/8190 |
