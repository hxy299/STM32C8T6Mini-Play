# TOF 两传感器配置说明（当前硬件）

> 状态：**当前只用 2 颗 VL53L0X**。
> 本文说明装在哪里、怎么配、以及**哪些方向是没有保护的**。

---

## 1. 安装位置

```text
        ┌─────────────────┐
        │                 │
        │   [TOF3] 前脸    │  ← 朝前，测障碍（距离变近 = 危险）
        │                 │
        └────[TOF0]───────┘  ← 前底面，朝下，测桌沿（距离变远 = 危险）
```

| 编号 | 位置 | 朝向 | 职责 | 危险方向 |
|---|---|---|---|---|
| **TOF0** | 底部前 | 朝桌面 | 桌沿检测 | 距离**变远** |
| **TOF3** | 前脸 | 朝前方 | 障碍检测 | 距离**变近** |

两者语义相反，阈值不能共用，这一点代码里本来就分开了
（`TOF_EDGE_MM = 80` / `TOF_OBSTACLE_MM = 150`）。

---

## 2. 接线

| 信号 | TOF0（底部前） | TOF3（前脸） |
|---|---|---|
| VIN | 3.3V | 3.3V |
| GND | 共地 | 共地 |
| SCL | **PB6** | **PB6**（共用） |
| SDA | **PB7** | **PB7**（共用） |
| **XSHUT** | **PA4** | **PA8** |

> ⚠️ **XSHUT 必须各自独立，而且各接一个 10 kΩ 下拉到 GND。**
> 没有下拉时，上电瞬间芯片状态不确定，地址分配会随机失败，
> 表现为开机自检里 `online` 少一位。

> ⚠️ 上电顺序：固件会把所有 XSHUT 拉低 → 逐个拉高 → 逐个改地址。
> 所以**接线时两颗的 XSHUT 不要接反**，否则会分配到错误的编号上。

### 地址分配结果

| 编号 | 出厂地址 | 改后地址 |
|---|---|---|
| TOF0 | 0x29 | **0x30** |
| TOF3 | 0x29 | **0x33** |

编号与物理位置固定绑定。即使只装两颗，TOF3 也一定是 0x33 ——
这样以后补上 TOF1/TOF2 时，已有那颗的地址不会漂移。

## 3. 配置字

默认值已改为两颗：

| 位 | 功能 | 值 |
|---|---|---|
| bit1 | TTS | ✅ |
| bit2 | 蓝牙 | ✅ |
| bit3 | **TOF0 底部前** | ✅ |
| bit4 | TOF1 底部左 | ❌ 没装 |
| bit5 | TOF2 底部右 | ❌ 没装 |
| bit6 | **TOF3 前脸** | ✅ |

```text
配置字 = 0x02 | 0x04 | 0x08 | 0x40 = 0x4E
```

设置命令：

```cmd
cmd> s 0000004E
```

> ⚠️ 老板子的配置存在 Flash 里，**重新烧固件不会覆盖**。
> 必须手动发一次 `s 0000004E`，或者先擦掉配置页再上电。

### 以后补上两颗怎么办

改 `User/app_config.h`：

```c
#define CFG_DEFAULT  (CFG_TTS_EN | CFG_BT_EN | CFG_TOF0_EN | \
                      CFG_TOF1_EN | CFG_TOF2_EN | CFG_TOF3_EN)   // 0x7E
```

或者直接发 `s 0000007E`。

## 4. ⚠️ 方向盲区（最重要的一节）

**只有一颗底部传感器，桌沿保护不是整圈的。**

| 动作 | 有没有保护 | 说明 |
|---|---|---|
| **前进** | ✅ 有 | TOF0 就在前方底面，前缘越过边界立刻发现 |
| **后退** | ❌ **没有** | 尾部先悬空，但 TOF0 仍悬在桌面上方，读数不变 |
| **原地左转** | ⚠️ 部分 | 只有前向一个参考点，侧向越界发现不了 |
| **原地右转** | ⚠️ 部分 | 同上 |

### 这意味着什么

**后退时机器人会直接掉下桌子，而固件不会拦。**

这不是 bug，是单传感器拓扑的物理限制。三颗（前 + 左 + 右）才能覆盖整圈，
两颗（前 + 后）能覆盖前后但不能覆盖侧向。

### 当前建议的使用方式

| 场景 | 做法 |
|---|---|
| 演示 / 展示 | 只在桌面中央区域活动，前进为主 |
| 调试后退 | 手动盯着，或先 `bck` 一小段（200 步）就 `st` |
| 靠墙 / 靠边 | 先把机器人摆回桌子中间再操作 |

### 固件里的提示

开机自检会打印：

```text
 WARN   : bottom TOF only 1/3 -> BACKWARD IS UNPROTECTED
```

看到这行就是提醒：**别指望后退有保护。**

## 5. 验收

### 5.1 开机自检

```text
 tof    : en=0x9 online=0x9  poll=10ms  edge>80mm obs<150mm
```

| 字段 | 期望值 | 含义 |
|---|---|---|
| `en=0x9` | 0x9 | bit0 = TOF0，bit3 = TOF3 |
| `online=0x9` | 0x9 | 两颗都起来了 |

> ⚠️ **这里的位图是"传感器编号"，不是配置字。**
> TOF0 → bit0 = 0x01，TOF3 → bit3 = 0x08，合起来 **0x9**。
> 不要和配置字 `0x4E`（bit3/bit6）搞混：两者编号体系不同。
>
> 如果 `online` 少了对应位 → 那一颗没起来，查接线 / 供电 / XSHUT 下拉。

### 5.2 实时看距离

```cmd
cmd> tofd 15
```

预期输出（`T0` 是底部前，`T3` 是前脸；`T1`/`T2` 应为 `----`）：

| 传感器 | 正常值 | 说明 |
|---|---|---|
| T0 | 15~40 mm | 底盘离桌面的高度 |
| T1 | `----` | 没装 |
| T2 | `----` | 没装 |
| T3 | 前面没东西时 > 300 mm 或 `----` | 有障碍物时骤降 |

### 5.3 桌沿触发测试

1. 让机器人**前进**到桌边
2. 观察是否：`EDGE_DETECTED` → 立即停 → 自动后退 200 步
3. 之后 `fwd` 应该被 NAK，`bck` 应该被允许，`c` 清除故障

### 5.4 障碍触发测试

把手放到前脸传感器前方 10 cm 处：

1. 应上报 `OBSTACLE_DETECTED`
2. `fwd` 被拒，`bck` / 转向允许
3. 手移开（> 200 mm）后自动恢复

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `online` 只有一位 | 另一颗 XSHUT 没接 / 没下拉 | 查 PA4 / PA8 和 10 kΩ 下拉 |
| 两颗都读 8190 | I²C 没通 | 查 PB6/PB7 上拉（模块自带 4.7 kΩ 即可） |
| 读数忽大忽小 | 供电不足或环境光干扰 | 3.3V 就近加 100 nF |
| T3 一直很近 | 阈值 150 mm 太保守，前脸有遮挡 | 改 `TOF_OBSTACLE_MM` 或调整安装角度 |
| 桌沿不触发 | `TOF_EDGE_MM=80` 比实际离桌高度大太多 | 实测桌面高度后调整，见下 |

### 阈值怎么调

| 参数 | 默认 | 含义 | 调整方法 |
|---|---|---|---|
| `TOF_EDGE_MM` | 80 | 超过判为桌沿 | 实测正常贴桌读数 + 20 mm |
| `TOF_EDGE_RECOVER_MM` | 60 | 回到此值解除 | 比上面小 20 mm |
| `TOF_OBSTACLE_MM` | 150 | 小于判为障碍 | 按机身尺寸定，别小于自身长度 |
| `TOF_OBSTACLE_RECOVER_MM` | 200 | 远离到此解除 | 比上面大 50 mm |

正常贴桌读数一般是 15~40 mm（取决于底盘高度），所以 80 mm 的阈值
留了约 40 mm 余量，够用。如果底盘更高，要相应调大。
