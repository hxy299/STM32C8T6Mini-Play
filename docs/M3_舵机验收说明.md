## 1. 接线

```
SG90 舵机                STM32F103C8T6
  橙线（信号） ────────→  PA0  (TIM2_CH1)
  红线（VCC）  ────────→  外部 5 V   ★ 不要从 MCU 3.3V 取电
  棕线（GND）  ────────→  GND（与 MCU 共地）
```

**⚠️ 两条硬性要求：**

1. **舵机必须独立 5 V 供电**（SG90 堵转约 700 mA）。
   从 MCU 的 3.3 V 取电会把电源拉塌，导致 MCU 复位。
2. **PA0 上建议加 10 kΩ 下拉到 GND**。
   复位瞬间 GPIO 是浮空的，下拉可以保证舵机不会乱抖一下。

> 舵机信号是 3.3 V 逻辑，SG90 的输入门限约 2.0 V，**可以直驱，不需要电平转换**。

## 2. 编译前必做：打开舵机功能位

舵机默认是**关闭**的（`CFG_DEFAULT` 里不含 `CFG_SERVO_EN`）。
两种打开方式：

### 方式 A（推荐，不动固件）：用命令打开

```bash
# 0x7A 默认 -> 加 bit0 变成 0x7B
python tools\pc_link_test.py COM5
cmd> s 0000007B
```

改完会写进 Flash，**重启后仍然有效**。

### 方式 B：改默认值

`User/app_config.h`：

```c
#define CFG_DEFAULT   (CFG_SERVO_EN | CFG_TTS_EN | CFG_TOF0_EN | \
                       CFG_TOF1_EN | CFG_TOF2_EN | CFG_TOF3_EN)   /* = 0x7B */
```

## 3. 判据

### 3.1 启动横幅

舵机开启时应看到：

```
 servo  : ON  PA0/TIM2_CH1 50Hz  center=1500us pulse=1500us range=±45 deg
```

关闭时：

```
 servo  : OFF (CFG_SERVO_EN=0, TIM2 not started)
```

### 3.2 逐条验收

| # | 操作 | 判据 |
|---|---|---|
| 1 | `s 0000007B` | ACK，并且**舵机立刻上电回中位**（0°） |
| 2 | `sv 0` | ACK(OK)，舵机在中位 |
| 3 | `sv 45` | ACK(OK)，**舵机转到 +45° 极限且不持续抖/堵转** |
| 4 | `sv -45` | ACK(OK)，转到 -45° 极限 |
| 5 | `sv 180` | **ACK(CLAMPED)**，实际只到 +45°（不会撞坏） |
| 6 | `sv -180` | **ACK(CLAMPED)**，实际只到 -45° |
| 7 | `sv 30 600` | 用 600 ms **平滑**转到 30°（肉眼可见缓动，不是瞬跳） |
| 8 | `sc` | 自动扫 0 → -45 → +45 → 0，每段 600 ms 缓动 |
| 9 | `s 0000007A`（关舵机位） | **舵机立刻失力**（不再保持角度），TIM2 停止 |
| 10 | 关舵机后再 `sv 0` | 返回 **NAK(FEATURE_DISABLED)** |
| 11 | 重新 `s 0000007B` | 舵机重新上电回中位，`sv` 恢复可用 |

> **第 5/6 条是最重要的安全判据**：无论上位机发多大的角度，
> 舵机都不能超出 ±45°。这是软件限幅，与机械限位是两回事。

## 4. 舵机映射原理（便于调机械中位）

```
脉宽 = 1500 + deg × 500 / 45        （单位 us）

deg = -45  -> 1000 us
deg =   0  -> 1500 us   （中位）
deg = +45  -> 2000 us
```

**如果装配后机械中位不在正前方**，改 `app_config.h` 的
`SERVO_CENTER_US`（例如 1480 或 1520），**不要**在代码里对角度做偏移，
否则限幅会跟着偏。

`SERVO_HALF_RANGE_US`（默认 500）是 ±45° 对应的脉宽跨度。
如果你的舵机实际行程偏大/偏小，调这个值。

## 5. 常见问题

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 舵机完全不动，但 `sv` 返回 ACK | ① 信号线没接 PA0 ② 舵机没单独供电 | 量 PA0 是否有 50 Hz 脉冲；量舵机红线是否 5 V |
| 舵机抖动 / 嗡嗡响不停 | 角度顶到机械限位；或电源不够 | 把 `SERVO_MAX_DEG` 临时改小试；换 ≥1 A 电源 |
| 舵机转一下就回中 | MCU 复位了（电源被拉塌） | 舵机改独立供电 |
| `sv` 返回 NAK(0x06 FEATURE_DISABLED) | `CFG_SERVO_EN=0` | `s 0000007B` |
| 角度方向反了 | 舵机安装方向 | 在 `SERVO` 命令里取负号，或改 `app_config.h` 的映射符号 |
| 缓动看不出来 | `ms` 太短 | 用 `sv 30 1500` 试 |

## 8. ⚠️ 踩坑记录：`NAK(0x08 NOT_IMPLEMENTED)` 不是接线问题

### 8.1 现象

```
cmd> sv 0
  --> TX a5 01 02 00 02 03 00 00 00 9f 8f
  <-- RX TYPE=2 SEQ=2 OP=0x82(NAK) LEN=2  status=0x08(NOT_IMPLEMENTED)  detail=0x02(SERVO)
```

舵机完全不动，且返回 `NAK(0x08 NOT_IMPLEMENTED)`。

### 8.2 真正原因

**板子里跑的还是 M0~M2.5 的旧固件**，舵机代码根本没编译进去。

旧固件的分发逻辑里，`OP_SERVO` 和 `OP_MOVE` / `OP_TTS` / `OP_TOF_CFG` 一起归到
"未实现"分支，所以才会返回 `status=0x08`。

> **`0x08 NOT_IMPLEMENTED` = 固件里没有这个命令，与接线的下拉电阻完全无关。**
> PA0 的 10 kΩ 下拉只是防止上电瞬间 GPIO 浮空导致舵机抖一下，
> **不加也能正常控制**。

### 8.3 判据：怎么确认"固件刷进去了"

固件在 PONG 里带了 **`impl` 功能实现位图**（第 11 字节），
上位机用一条命令就能看到板子里到底有什么：

```
cmd> v
[CAPS] 查询固件能力
  uptime : 3.677 s
  config : 0x0000007B [SERVO, TTS, TOF0...]
  flags  : 0x01  src=FLASH  blind=NO
  impl   : 0x31 [SERVO, CONFIG, CLEAR_FAULT]

  逐项：
    ✔ SERVO        (bit0)
    ✘ MOVE         (bit1)
    ✘ TTS          (bit2)
    ✘ TOF          (bit3)
    ✔ CONFIG       (bit4)
    ✔ CLEAR_FAULT  (bit5)

  → SERVO 已实现，可执行 sv <deg> [ms]
```

如果显示：

```
  impl   : ??   ← 旧固件（M0~M2.5 或更早），PONG 无 impl 字节
```

**那就是没刷新固件**，与硬件无关。

### 8.4 位图定义（新增功能时同步加位）

| 位 | 宏 | 含义 |
|---|---|---|
| bit0 | `IMPL_SERVO` | M3：`SERVO` 已实现 |
| bit1 | `IMPL_MOVE` | M4/M5：`MOVE` 已实现 |
| bit2 | `IMPL_TTS` | M9：`TTS` 已实现 |
| bit3 | `IMPL_TOF` | M7：`TOF_CFG` 已实现 |
| bit4 | `IMPL_CONFIG` | M2.5：`SET/GET_CONFIG` |
| bit5 | `IMPL_CLEAR_FAULT` | M2.5：`CLEAR_FAULT` |

当前 `IMPL_MASK_CURRENT` = `SERVO | CONFIG | CLEAR_FAULT` = **0x31**。

### 8.5 重烧后应该看到的编译变化

| 项 | M0~M2.5 | M3 |
|---|---|---|
| 编译输出 | 无 `servo.c` | 应出现 `compiling servo.c...` |
| Code | 13884 | **约 15.5 K（明显变大）** |
| Error | 0 | **0** |

> 如果 Rebuild 报错，Keil 会保留旧的 `.axf`，此时点 Load 可能仍然烧进旧固件。
> **务必确认 `0 error` 后再 Load。**

### 8.6 限幅测试要用 `sv 100` 而不是 `sv 180`

协议里 `deg` 是**有符号单字节**（int8，范围 -128..127），
所以 `sv 180` 是**工具端就拒绝**了，根本发不出去。

要测限幅请用：

```bash
cmd> sv 100      # 应返回 ACK(CLAMPED)，实际只到 +45°
cmd> sv -100     # 应返回 ACK(CLAMPED)，实际只到 -45°
```
